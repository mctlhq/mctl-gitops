# Image names under ghcr.io/mctlhq that a team may build into and run.
#
# Tenant builds push ghcr.io/mctlhq/<component_name>, and tenant services run
# ghcr.io/mctlhq/<component_name>, so the component name IS the image name.
# platform-gitops/argo-workflows/scripts/check-image-name.sh decides, for a
# team T and a name N, in this order:
#
#   1. `grant T N` or `grant * N` below      -> allowed
#   2. `reserved N`, or N starts with a      -> refused
#      `reserved-prefix`
#   3. another team already has services/<other>/N, or a values.yaml under
#      services/<other>/ runs ghcr.io/mctlhq/N -> refused
#   4. otherwise                            -> allowed
#
# Read by the deploy-service and preview-deploy validation (Argo) and by
# .github/workflows/build-image.yaml before it pushes. A line this script does
# not understand makes every check refuse, so keep to the three forms below.
# tests/test_check_image_name.py keeps this file complete: every image the
# platform references outside platform-gitops/services/ must be reserved here,
# and every service that exists today must pass.

# --- Platform images: built by release-deploy or by hand, never by a tenant.
reserved-prefix mctl-
reserved grafana-iac
reserved mc
reserved newton-mcp-gateway
reserved openclaw-whisper-builder
reserved pfeifenpatenschaft-backend
reserved portfolio
reserved projects-mcp
reserved seerrsense
reserved vault-iac
reserved zitadel-iac

# --- Reviewed grants. Each one is an existing service whose name is reserved
# --- above or shared between teams; add a line here only in review.

# Platform images built from platform-gitops/images/ and dispatched by hand
# with team "platform" (not a tenant; wft-create-tenant refuses the name).
grant platform grafana-iac

# openclaw services run the fixed image mctl-openclaw (service-templates/
# openclaw), never an image named after the component, and their build input is pinned
# to mctlhq/mctl-openclaw by mctl-api. The name is shared by every team that
# deploys one.
grant * openclaw
