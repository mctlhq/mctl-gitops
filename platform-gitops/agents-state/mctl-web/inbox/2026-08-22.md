## Source: cve
- **CVE-2026-71320 — Nuxt Server-Side RCE via runtime template injection** — attacker can inject a template key through `/__nuxt_island/` props into a dynamic component when `vue.runtimeCompiler: true` is enabled, causing template execution in the Nitro process; fixed in Nuxt 3.21.10 / 4.5.1. https://advisories.gitlab.com/npm/nuxt/CVE-2026-71320/
- **Nuxt island renderer CPU-exhaustion DoS** — unauthenticated POST with large JSON body to `/__nuxt_island/...` wastes CPU on Nitro's single event loop, delaying concurrent requests (hash validated after decoding); fixed in 3.21.10 / 4.5.1.
- **Nuxt server-island SSR memory-exhaustion DoS** — unauthenticated attacker can use a server island `v-for` prop to trigger unbounded SSR memory allocation and crash the Nuxt process; fixed in 3.21.10 / 4.5.1.
- **Nuxt routeRules case-sensitivity auth bypass (incomplete fix follow-up)** — mixed-case `routeRules` keys can fail to match case-folded lookups when `router.options.sensitive` is false, dropping `appMiddleware` authorization gates; incomplete fix for prior CVE-2026-53721, now fixed in 3.21.10 / 4.5.1. Our pinned Nuxt is 4.3.1, below the 4.5.1 fixed version — worth flagging given these are auth/RCE-adjacent.
- **workerd memory-corruption bugs (5 found)** — includes an out-of-bounds read in URLPattern letting one Worker read another tenant's secrets across the shared process heap, and a use-after-free in `node:zlib` allowing sandbox escape to native code on the host; self-hosted workerd deployments advised to update to v1.20260619.1. https://thehackernews.com/2026/08/cloudflare-workers-spectre-attack-leaks.html
- **Cloudflare Workers Spectre-class side-channel attack** — researchers demonstrated live JWT exfiltration from co-located Workers at up to 12 bits/sec with >99% accuracy, a 360x improvement over prior Spectre attacks on Workers via JS-level algorithmic changes; Cloudflare published findings Aug 19 2026 confirming three mitigation layers already deployed. https://www.techtimes.com/articles/325073/20260820/cloudflare-workers-spectre-exploit-stole-auth-tokens-360-faster-prior-attack.htm / https://blog.cloudflare.com/revisiting-spectre-attacks-on-workers/

## Top-3 (for spec-writer)

### 1. nuxt-security-patch: Upgrade Nuxt past 4.5.1 to close four CVEs
**Category:** security
**Impact:** 5
**Effort:** 3
**Rationale:** Four Nuxt CVEs (SSR RCE via runtime template injection, island-renderer CPU-exhaustion DoS, server-island SSR memory-exhaustion DoS, and an auth-bypass follow-up on `routeRules` case-sensitivity) are all fixed in Nuxt 3.21.10/4.5.1, and our pin (4.3.1) is below the fix. This is squarely inside our architecture (Nuxt is our core framework, ADR 0001 confirms it, no rejection applies), directly affects the `admins` tenant, and includes an unauthenticated RCE — the highest-severity, most actionable finding in this batch. Not a `labs` memory concern since mctl-web only runs in `admins`; effort is a version bump plus regression testing of island rendering/SSR/routeRules, not an architecture change.
**Source:** CVE-2026-71320 and three related Nuxt CVEs, inbox "Source: cve" section; fixed versions 3.21.10 / 4.5.1 vs. our pin 4.3.1 (context/architecture.md).
