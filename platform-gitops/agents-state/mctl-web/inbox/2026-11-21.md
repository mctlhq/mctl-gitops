## Top-3 (for spec-writer)

Caveat: the version baseline is inconsistent (architecture.md/ADR 0001 say Nuxt 4.3.1; current-version.md says 4.6.2). Confirm from `package.json`. Existing proposals with the same slugs already exist, so the spec-writer uses `-v2` suffixes. No item raises `labs` memory.

### 1. nuxt-4-6-4-security-upgrade-v2: Upgrade Nuxt to 4.6.4 (nitropack 2.13.6)
**Category:** security
**Impact:** 4
**Effort:** 2
**Rationale:** Fixes several Medium advisories (`//` bypass, `%2F` route rules, ReDoS, error leakage). It is still the latest release and the earlier proposal remains unimplemented as far as the state shows. Consistent with ADR 0001 (track Nuxt releases).
**Source:** nuxt v4.6.4 release; CVE-2026-128077/-128071/-128074/-128075.

### 2. nuxt-path-confusion-regression-tests-v2: Post-build path-normalization smoke tests
**Category:** security
**Impact:** 3
**Effort:** 2
**Rationale:** Repeated path-confusion advisories (`//`, `%2F`, `/%2e/`) suggest a cheap CI guard in `deploy.yml`. It should also check that production errors leak no details and that Worker `/api/*` rate limits behave the same for encoded variants.
**Source:** CVE-2026-128077, -128071, -128075.

### 3. worker-toolchain-bump-compat-date-v2: Bump wrangler/workerd to 1.20261120.1 and review compat date
**Category:** refactor
**Impact:** 2
**Effort:** 2
**Rationale:** workerd 1.20261120.1 is newer than the target in the earlier proposal. Of note: `fetch()` now throws on a malformed response head, which touches the Backstage, Telegram and Resend calls. Do not adopt the autogated features.
**Source:** workerd v1.20261120.1.
