## Top-3 (for spec-writer)

### 1. backstage-security-patch-bundle: Patch Backstage packages for Oct–Nov 2026 CVEs
**Category:** security
**Impact:** 5
**Effort:** 2
**Rationale:** A cluster of advisories hits plugins we run (scaffolder, kubernetes, techdocs, auth-node, catalog), including a critical 9.6 credential-exposure issue in the scaffolder, which is tied to mctl-gitops. Bumping to Backstage 1.56.3 (a minor/patch bump, not a major, so ADR 0001 is respected) covers all of them. Memory impact on `labs` is negligible, since the portal runs in `admins`.
**Source:** CVE-2026-106501, -106504, -106556/8, -106561, -106460, -115923; backstage v1.56.3.

### 2. playwright-1-65-upgrade: Upgrade Playwright to 1.65 for e2e
**Category:** refactor
**Impact:** 2
**Effort:** 2
**Rationale:** We use Playwright for e2e. 1.65 drops Node 20 testing (we're on 22/24, fine) and changes cookie matching, ARIA snapshots and TS class field semantics, so an early controlled bump avoids drift. The `failures` reporter is a CI DX gain.
**Source:** playwright v1.65.0.

### 3. techdocs-zensical-evaluation: Evaluate Zensical TechDocs engine ahead of Material for MkDocs sunset
**Category:** feature
**Impact:** 3
**Effort:** 3
**Rationale:** TechDocs is in use and its current engine depends on Material for MkDocs, which is shutting down. The experimental Zensical module is a migration path; a time-boxed spike now gives us a plan before forced migration. It must run in `admins` only. Not a rewrite; ADR 0001 is not affected.
**Source:** backstage v1.56.3 release notes.
