## Top-3 (for spec-writer)

### 1. backstage-security-patch-bump: Bump Backstage backend packages to patched versions (Oct 2026 CVE batch)
**Category:** security
**Impact:** 5
**Effort:** 2
**Rationale:** Eight medium-severity advisories hit catalog, scaffolder, kubernetes and proxy backends, all of which we run. Scaffolder log/event leaks expose credentials and the kubernetes leak bypasses masking. This is a patch-level bump within the current line, so it does not conflict with the ADR against immediate major bumps.
**Source:** CVE-2026-106496/98/502/504/506/561/491 (inbox, cve section)

### 2. rbac-location-update-permission: Adapt permission policy to the new catalog.location.delete requirement
**Category:** security
**Impact:** 3
**Effort:** 2
**Rationale:** From v1.57.4, updating a catalog location also needs `catalog.location.delete`. Our group-mapped RBAC could break catalog-import flows or grant more than intended. It must be reviewed before or during any upgrade to 1.57.x.
**Source:** backstage v1.57.4 release notes

### 3. playwright-1-65-1-upgrade: Upgrade Playwright to 1.65.1 and add post-upgrade catalog smoke e2e
**Category:** refactor
**Impact:** 2
**Effort:** 1
**Rationale:** 1.65.1 fixes a regression with decorated classes. A small e2e smoke test for scaffolder and catalog location refresh guards the Backstage upgrade, including the one-time location URL re-encoding. It adds no runtime memory in `labs`, since it is CI only.
**Source:** playwright v1.65.1; backstage v1.57.4 URL encoding change
