## Rollback

The change is additive and stateless. To roll back, revert the PR: remove `internal/mcp/usage.go`, the `AddTool` line, the `recordedHints` / `want` entries and the `docs/portal-allowlist.json` entry. Then ship the previous mctl-api image through the normal release (the ArgoCD app `admins-mctl-api`). No data, schema or HTTP contract is touched, so nothing needs migrating back. If only portal exposure is a concern, the entry is already `enabled: false`. If it was later flipped on, setting it back to `false` hides the tool on the portal without a code change.
