## Top-3 (for spec-writer)

### 1. go-toolchain-http2-dos-upgrade: Upgrade Go toolchain and x/net to fix HTTP/2 DoS advisories
**Category:** security
**Impact:** 5
**Effort:** 3
**Rationale:** mctl-api is internet-facing at api.mctl.ai, and a family of HTTP/2 DoS CVEs affects net/http and x/net. Go 1.24 is out of support, so fixes need Go 1.25.13+/1.26.6+ and x/net >= 0.62. Upgrading also unblocks the pgx 5.11 bump (requires Go 1.25).
**Source:** cve section, CVE-2026-56853, CVE-2026-33814, GO-2026-6603..6617.

### 2. mcp-go-v1-upgrade: Upgrade mark3labs/mcp-go 0.31 → 1.5.0 with bounded-read hardening
**Category:** security
**Impact:** 4
**Effort:** 4
**Rationale:** v1.5.0 bounds the SSE message body read and OAuth redirect handling, which hardens our public MCP endpoint and the Claude.ai connector OAuth flow. Large version jump; per ADR 0001 all 24 tools must be revalidated via MCP Inspector. Consistent with ADR 0001 (upgrade, not replace).
**Source:** github releases, mcp-go v1.5.0; cve section.

### 3. pgx-chi-bumps-realip-audit: Bump pgx to 5.11 and chi to 5.5, audit RealIP / rate-limit keying
**Category:** security
**Impact:** 3
**Effort:** 2
**Rationale:** pgx 5.11 carries a memory-safety/decoder hardening and startup-parameter injection fix; the connection-string parser changed, so DSN from Vault must be verified. chi RealIP spoofing could let clients evade httprate limits, so audit how the client IP is derived behind the ingress.
**Source:** github releases pgx v5.11.0, chi v5.5.0; cve section.
