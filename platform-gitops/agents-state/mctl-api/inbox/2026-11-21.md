## Top-3 (for spec-writer)

### 1. upgrade-mcp-go-v1-v2: Upgrade mark3labs/mcp-go from 0.31.0 to 1.6.0
**Category:** security
**Impact:** 5
**Effort:** 3
**Rationale:** 0.31.0 lacks Host validation (DNS rebinding) and protocol reliability fixes; v1.6.0 shipped 19 Nov. The public MCP endpoint is the main attack surface. Slug `upgrade-mcp-go-v1` already exists (target 1.5.x), so this is -v2 retargeting 1.6.0. Per ADR 0001, re-validate all 24 tools. GO-2026-6911 concerns the client transport only (we are a server) and has no fix, so it is not a blocker.
**Source:** mcp-go v1.6.0; GO-2026-6911.

### 2. upgrade-pgx-5-11-v2: Upgrade pgx/v5 from 5.8 to 5.11.0
**Category:** security
**Impact:** 4
**Effort:** 2
**Rationale:** Fixes critical memory-safety CVEs (5.9.0) and SQLi CVE-2026-41889 (5.9.2). Conn-string parsing now follows libpq, so DSNs need a staging check. Slug `upgrade-pgx-5-11` already exists, so -v2.
**Source:** pgx v5.11.0; CVE-2026-41889.

### 3. argocd-serversidediff-secret-leak-cve-2026-45737: Verify Argo CD is patched against Secret extraction via ServerSideDiff
**Category:** security
**Impact:** 4
**Effort:** 1
**Rationale:** mctl-api uses an ARGOCD_TOKEN to read application status; a Secret-extraction flaw in Argo CD could expose tenant secrets cross-tenant. Needs confirming the platform ArgoCD is >= 3.2.12/3.3.10/3.4.2 and the token scope is minimal. No resource increase for `labs`.
**Source:** GO-2026-5618 / CVE-2026-45737.
