## Top-3 (for spec-writer)

### 1. upgrade-mcp-go-v1: Upgrade mark3labs/mcp-go from 0.31.0 to 1.5.x
**Category:** security
**Impact:** 5
**Effort:** 3
**Rationale:** 0.31.0 predates the DNS-rebinding Host validation fix (0.56.0) and the SSE body-size bounds. The public MCP endpoint is the main attack surface. Consistent with ADR 0001, which requires re-validating all 24 tools on each bump.
**Source:** CVE-2026-81092; mcp-go v1.5.0 release.

### 2. upgrade-pgx-5-11: Upgrade pgx/v5 from 5.8 to 5.11.x
**Category:** security
**Impact:** 4
**Effort:** 2
**Rationale:** Two memory-safety advisories exist against pgx/v5. The service stores identities and audit logs in Postgres. The upgrade changes connection-string parsing, so it needs a staging check.
**Source:** GO-2026-4772, GO-2026-4771; pgx v5.11.0.

### 3. upgrade-chi-5-5-realip-audit: Upgrade chi to 5.5.0 and audit RealIP / httprate trust
**Category:** security
**Impact:** 4
**Effort:** 2
**Rationale:** RealIP spoofing can bypass IP-keyed rate limiting and falsify audit-log client IPs. The upgrade is small, and the audit confirms we only trust forwarded headers from the ingress.
**Source:** GO-2026-5777/5775/5774, GO-2026-4316; chi v5.5.0.
