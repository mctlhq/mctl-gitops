### Commits 8d3a185, e2e6d59 — feat(oauth): persist dynamic client registrations, idempotent per metadata / fix(oauth): bound client-store lookups and keep used DCR clients under churn
- **Date:** 2026-09-25
- **Type:** feat / fix
- **User-visible effect:** `POST /oauth/register` used to keep DCR client registrations in an in-memory map, so every pod rollout silently forgot a registration while the client (e.g. the Cloudflare MCP portal) kept using its now-invalid cached `client_id`.
