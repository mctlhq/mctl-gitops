### 2. argocd-helm-release-name-validation: Audit app names for the new Helm release-name validation (<=53 chars, valid Helm name)
**Category:** refactor
**Impact:** 3
**Effort:** 1
**Rationale:** The `apps` ApplicationSet generates Application names from `services/<tenant>/<svc>`, which are used as Helm release names with base-service. Long or invalid names would fail to sync after the 3.6.3 bump. A pre-upgrade audit is cheap and prevents a platform-wide sync failure.
**Source:** argo-cd v3.6.3 breaking-change note.
