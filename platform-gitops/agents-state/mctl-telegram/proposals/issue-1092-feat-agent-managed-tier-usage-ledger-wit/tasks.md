## Rollback

- Fastest: leave or turn off `MANAGED_RUNTIME_ENABLED`. The budget code runs only for the managed pool claim. Own workers and the cost route's legacy path are unaffected.
- To relax caps without a revert, raise `MANAGED_BUDGET_USD_*` or set a per-account override through the admin profile route. To unpause an account, null `budget_paused_until` with an admin update.
- Code revert: revert the PR. The `agent_usage` table and the two nullable columns are additive and can stay. Older code ignores them, and `budget_paused_until` already existed. The worker's 400 fallback keeps a new worker working against a reverted server.
