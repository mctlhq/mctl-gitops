## Rollback
The change is a single new directory with no references from the application, CI or release config. Roll back by reverting the PR (or `git rm -r experiments/media-engine-evaluation`). Local experiment resources are removed with `node experiments/media-engine-evaluation/bin/cleanup.mjs --run <id>`, which deletes only containers, networks and volumes labelled `io.mctl.experiment=media-engine-evaluation` with that run id, plus the run's own `runs/<id>/` root. No deployed service, database, GitOps file or release is affected, so no platform rollback is needed.
