## Rollback

- The producer is a new runner with no caller in mctl-agents. It runs only when the companion CWFT is
  submitted. Rolling back means reverting the mctl-agents PR, or simply not submitting the CWFT. Reverting
  the mctl-gitops companion PR removes the profile and the CWFT.
- If receipts were stored after enablement and must be disregarded, the operator turns
  `REVIEW_WORKER_INGEST_ENABLED` off in mctl-gitops; new submits get 501 again. Stored receipts are
  append-only and are not consumed by any gate yet (ADR 025), so no merge or approval behaviour depends on
  them.
- `evidence_producer` changes are additive (a new stage value and a new method). Reverting them does not
  affect envelopes already sealed for other stages.
