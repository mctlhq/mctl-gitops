## Rollback
Revert the PR. That restores `setting_sources=["project"]` in the four builders, removes strict MCP config from all
but the gateway branch, restores the root-only instruction-file wording, and restores the old
`_stage_implementer_agent`, which copies `implementer.md` into the clone. No data or gitops state needs to be undone.

Do not use `TARGET_CLONE_STRICT_MCP_CONFIG = False` as an emergency lever. It also removes strict mode from the gateway
branch (ADR 017, #242), and on CLI 2.1.301 it reopens nothing by itself, because `[]` already stops `.mcp.json`. If
target-repo settings must come back temporarily, setting `TARGET_CLONE_SETTING_SOURCES = ["project"]` reopens the
hook, `apiKeyHelper` and `env` channels while strict mode still blocks `.mcp.json`; that is a deliberate decision, not
a quiet fix. The programmatic `agents=` persona is harmless alongside either, because the same name resolves to the
same content.
