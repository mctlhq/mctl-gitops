## Rollback

Every change is confined to four source files plus one journal entry and one
script section, with no state outside the repository. Roll back by reverting
the merge commit for this cycle (`git revert -m 1 <merge-sha>`), which restores
the literal `<h1 class="hero-name">Dmitrii Mashkov</h1>`, the
`var(--font-editorial)` declaration, the dictionary without `heroName`, the
tests and the `check-dist.mjs` section together — the tests removed by the same
revert are the only thing that would fail against the restored page, so the
suite stays green either way. `public/styles/site.css` is regenerated on the
next `prebuild` and needs no manual cleanup. If the revert lands after a
release, deploy the previous image tag with
`mctl_rollback_service(team_name='labs', component_name='portfolio', target_tag=<previous>)`;
no font asset, licence file or vendored artifact is added or removed by this
cycle, so there is nothing else to undo.
