## Top-3 (for spec-writer)

### 1. go-toolchain-security-upgrade: Bump Go 1.24 to the latest patched stable release
**Category:** security
**Impact:** 5
**Effort:** 2
**Rationale:** The 2026 Go stdlib CVE batch includes crypto/tls DoS (CVE-2026-32283) and crypto/x509 chain-building DoS (CVE-2026-32280), which hit every outbound TLS connection mctl-agent makes (Anthropic API, GitHub API, AlertManager/Telegram webhooks), plus html/template XSS (CVE-2026-39823) and cmd/go supply-chain issues (CVE-2026-42501, CVE-2026-39819, CVE-2026-27140) that matter for our build pipeline. Go 1.27.0 is now current (released 2026-08-19); a toolchain bump is self-contained (no application API surface change) and is the highest-leverage security fix available this cycle.
**Source:** github releases — Go 1.27.0; cve — Go stdlib batch (Red Hat advisories: CVE-2026-42499, CVE-2026-42501, CVE-2026-39823, CVE-2026-39819, CVE-2026-32283, CVE-2026-32280, CVE-2026-27144, CVE-2026-27140, CVE-2026-27143).

### 2. go-chi-v5.3.2-router-upgrade: Upgrade chi router from 5.2.1 to 5.3.2 and verify RedirectSlashes CVE status
**Category:** security
**Impact:** 3
**Effort:** 1
**Rationale:** chi routes every ingress path in mctl-agent (AlertManager webhook, Telegram webhook, REST API, MCP endpoint). v5.3.2 is a small 4-commit diff that fixes a real Mount()/Route() handler-collision bug, dedups the Allow header on 405s, and closes a compress-middleware wildcard hole — low-risk, high-confidence bump. It's also the natural checkpoint to explicitly verify whether CVE-2025-69725 (Open Redirect in `RedirectSlashes`, affecting >=5.2.2) is actually fixed in 5.3.2, since the release notes don't confirm it — the spec should not assume the CVE is silently resolved by this bump.
**Source:** github releases — go-chi/chi v5.3.2; cve — CVE-2025-69725 (GHSA-mqqf-5wvp-8fh8).

### 3. sqlite-stack-dependency-update: Update modernc.org/sqlite (1.34→1.57.0) and its transitive libc dependency, with CVE verification
**Category:** security
**Impact:** 3
**Effort:** 2
**Rationale:** modernc.org/sqlite backs the tickets DB and skill-metrics store and is 20+ minor versions behind upstream. CVE-2026-50812 (Session Extension DoS) should be treated skeptically — the researcher flagged that 54/55 recent SQLite advisories from the same reporting account look fabricated — so this alone is not a slam-dunk critical fix; the spec should verify it against sqlite.org/cves.html before treating it as confirmed. However, the transitive modernc.org/libc CVE-2025-26519 (CVSS 8.1) is a separately-sourced, independent advisory on a dependency we pull in regardless, which justifies the update on its own. This does not conflict with ADR 0001 (SQLite stays; no engine change proposed) and is a pure-Go dependency bump with no CGO implications.
**Source:** cve — CVE-2026-50812, CVE-2025-26519; github releases — modernc.org/sqlite v1.57.0.
