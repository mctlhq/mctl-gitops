## Top-3 (for spec-writer)

### 1. openclaw-upstream-upgrade-assessment: Assess upgrade path from 2026.7.11-beta.2 to a patched mainline/LTS release
**Category:** security
**Impact:** 5
**Effort:** 4
**Rationale:** All three tenants are still on `2026.7.11-beta.2`, three release trains behind upstream (2026.7.35 LTS "critical security updates", 2026.9.5, 2026.9.6), and a third-party signal states 2026.8.1+ fixes the two Sep-11 High-severity GHSA advisories that our deployed version predates. This is the single highest-impact, architecturally-clean item (plain version bump, no rejected pattern from ADR-0001/0002) but must follow the accepted `labs` → `admins` → `ovk` rollout order from ADR-0001, and the spec must explicitly budget/monitor `labs` memory headroom before and during the canary rollout since `labs` is already at ~72-73% of its (recently resized) memory quota — any regression there is risky per the platform's `labs`-memory constraint. Unconfirmed adjacent signals (CCB Belgium 1-click RCE advisory, Infosecurity "six new vulnerabilities" article, betterclaw.io's unverified 543-CVE aggregate) should be folded in as supporting research/validation steps in this same proposal rather than spun out separately, since none of them yet name a specific GHSA/CVE ID or version range.
**Source:** github releases (2026.9.6, 2026.7.35, 2026.9.5, deployed baseline 2026.7.11-beta.2) + cve ("update to 2026.8.1+" snippet, 10 unchanged GHSA advisories) + mctl metrics (labs 14Gi/72% memory).

### 2. baileys-cve-48063-vendored-version-check: Confirm and, if needed, patch the fork's vendored Baileys version against CVE-2026-48063
**Category:** security
**Impact:** 4
**Effort:** 2
**Rationale:** CVE-2026-48063 (Baileys message/history spoofing, CVSS 9.3 critical) has now been unconfirmed against our actual vendored Baileys version for three consecutive research passes; Baileys is an explicit dependency in `context/architecture.md` (WhatsApp channel) so this is squarely in-scope, and a version check plus targeted bump is low-effort/low-footprint (does not resemble anything rejected by ADR-0002, and a Baileys patch bump is not expected to meaningfully raise memory usage in `labs`). Low effort combined with a critical CVSS score makes this a quick, high-value win independent of the larger upstream upgrade in #1.
**Source:** cve (CVE-2026-48063, https://app.opencve.io/cve/CVE-2026-48063) + architecture.md dependency list (Baileys).

### 3. ovk-empty-logs-pod-health-investigation: Investigate ovk's 2nd consecutive week of empty logs and low pod utilization
**Category:** performance
**Impact:** 4
